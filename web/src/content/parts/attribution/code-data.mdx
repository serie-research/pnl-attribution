The <a href={citation.repository}>source repository</a> holds the whole page: the text, the presentation view, the notebook, the simulation package and the instructions to rebuild everything, offline if needed.
The files below reproduce the signal study of section 3 without cloning the repository.
The <SourceLink path="code/reproduce.zip">source bundle</SourceLink> contains them and the scripts that export each figure's data; its <SourceLink path="code/README.md">instructions</SourceLink> say how to install the dependencies and which studies the bundle reruns. The notebook also runs in a browser without installation, in the <a href={`${import.meta.env.BASE_URL}lab/`}>browser lab</a>; its first load downloads about 25 MB.

All times are from one local run and depend on hardware.

From the extracted bundle, run `uv sync --group dev` to install the Python dependencies.
These commands rerun the study of section 3.5 and print its tables:

```sh
uv run python -m sim.signal_attribution.run_local full results --workers 8
uv run python -m sim.signal_attribution.summarise results
```

Its tests run with `uv run pytest sim/signal_attribution/tests`.
